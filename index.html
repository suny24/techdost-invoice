Every invoice you save can also be added as a new row in your own Google Sheet automatically. Set this up once:

Step 1 — Open a new Google Sheet, go to Extensions → Apps Script, and paste the code below.
Already set this up before? — Open your existing Apps Script project, select all the old code and delete it, paste this new version in its place, then click Deploy → Manage deployments → ✎ (edit) → Version: "New version" → Deploy — this last step is essential; just saving the code (Ctrl+S) does NOT update your live Web App, it keeps serving the old code until you deploy a new version. The Invoices sheet is now columnar — Product, Qty, Price, Cost, Supplier, etc. are each their own column, and every product gets its own row (so multi-product invoices span a few rows sharing the same Invoice No). A "Suppliers" tab is also created automatically as a running purchase ledger. This only applies to invoices saved from now on — older rows already in the Sheet keep their old single-cell format; you can leave them or delete them.
If your Invoices/Expenses tab has data but no header row (row 1 is a real record, not labels like "Invoice No"): that happens when the tab already existed — even empty — before the script's first run, so the header line got skipped. This is fixed in the code above. To repair a sheet already in that state: select and delete all existing rows in the affected tab (right-click the row numbers → Delete rows), redeploy the fixed code above, then in this app go to Settings → "Push local data to Sheet" to resend everything from this device with correct headers and columns.
What lives where: "History", "Customers", and "Suppliers" inside this app are just views — built automatically from the Invoices sheet (and the auto-created Suppliers/Expenses sheets) every time a sync happens. They don't need their own separate Sheet tabs. The Suppliers sheet tab only gets rows once a product actually has a Supplier filled in; the Expenses sheet only appears once you add an expense from the Expenses tab.

Hosting on GitHub Pages (works on mobile too)

1. Create a new GitHub repository (e.g. techdost-invoice).
2. Upload this file and rename it to index.html.
3. Go to Settings → Pages → set Source to the main branch, root folder.
4. Your tool will be live at https://yourusername.github.io/techdost-invoice/ — open this link on your phone and add it to your home screen for quick access.

Important: invoice history is saved in this browser only (per device), so it won't automatically appear on a different phone or computer. If you use the tool from more than one device, set up Google Sheet sync above — that Sheet becomes your shared record across all devices. Exporting CSV from History anytime works as a manual backup.
